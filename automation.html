PowerShell Automations

Windows-focused automations supporting Active Directory, endpoint operations, and reporting.

Active Directory & GPO Weekly Information Pull

Purpose: Produce a weekly snapshot of AD health, privileged groups, and GPO changes for visibility and audit readiness.

  • Exports OU structure, group membership (including privileged groups), and user account status.
  • Collects GPO reports and highlights newly created/modified policies.
  • Outputs results to CSV/HTML and emails a weekly summary to IT leadership.
PowerShell Active Directory GPO Reporting

Patch Compliance & Endpoint Inventory Report

Purpose: Automate endpoint compliance reporting and highlight machines missing critical updates.

  • Pulls device inventory and OS/build information from management tooling and local queries.
  • Flags devices missing patches beyond a defined threshold (e.g., 14–30 days).
  • Generates a remediation list for follow-up and change window scheduling.

Automated User Provisioning + Group Assignment Workflow

Purpose: Standardize onboarding by automatically creating users, assigning groups, and applying baseline policies.

  • Creates user accounts using standardized naming and attribute templates.
  • Assigns department-based AD groups and access profiles.
  • Triggers a “new hire checklist” output for IT operations (accounts, apps, device readiness).

API-driven automations supporting cloud services, data extraction, and workflow improvement.

Microsoft Graph API Integration: Entra ID → SharePoint Data Pull

Purpose: Use Microsoft Graph to extract Entra ID and SharePoint information for reporting and operational visibility.

  • Authenticates using app registration (least-privilege scopes).
  • Pulls targeted SharePoint list/library data and normalizes output for reporting.
  • Supports scheduled exports to CSV/JSON for dashboards or audits.

Security Alert Normalization & Triage Helper

Purpose: Reduce alert fatigue by normalizing alert data into a consistent format and prioritizing by severity and asset criticality.

  • Ingests alerts via API or exported JSON/CSV.
  • Tags alerts with severity, category, and recommended next actions.
  • Outputs a daily triage queue for faster response and tracking.

Asset & License Reconciliation Report

Purpose: Automatically reconcile user/device inventory with licensing assignments to identify mismatches and reduce cost waste.

  • Pulls user/device inventory from APIs and compares against license assignments.
  • Flags inactive accounts still consuming licenses and devices missing required entitlements.
  • Produces a remediation list for IT and Finance review.
