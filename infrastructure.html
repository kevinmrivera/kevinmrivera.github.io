Hybrid Infrastructure Architecture

Designing and maintaining secure, scalable environments integrating on-premise systems with modern cloud platforms.

On-Premise Enterprise Infrastructure

  • Administer Windows Server environments supporting production workloads and business applications.
  • Manage Active Directory including OU structure, Group Policy enforcement, and role-based access control (RBAC).
  • Maintain DNS and DHCP services to ensure reliable internal network operations.
  • Execute operating system upgrades and enterprise migrations using SCCM deployment strategies.

Technologies: Windows Server 2019–2022, Active Directory, GPO, DNS, DHCP, SCCM

Cloud & Azure Services

  • Administer Azure IaaS and identity services within hybrid enterprise environments.
  • Implement RBAC, Conditional Access, and Multi-Factor Authentication to strengthen access controls.
  • Maintain secure identity synchronization between on-prem AD and Entra ID.
  • Support Azure virtual machines, storage accounts, and governance policies.

Technologies: Microsoft Azure, Entra ID (Azure AD), RBAC, Conditional Access, MFA

Hybrid Identity & Endpoint Integration

  • Maintain hybrid Active Directory architecture integrating on-prem infrastructure with cloud identity.
  • Manage Windows and macOS endpoints through Intune and MDM platforms.
  • Enforce compliance baselines and security posture standards across distributed devices.

Technologies: Intune, MDM, Hybrid AD, Endpoint Compliance

Infrastructure Automation & Operational Excellence

  • Develop PowerShell scripts to automate patching, reporting, and administrative workflows.
  • Standardize deployment procedures to reduce configuration drift and improve consistency.
  • Improve operational efficiency through repeatable automation frameworks.

Technologies: PowerShell, CLI, Automation Frameworks
